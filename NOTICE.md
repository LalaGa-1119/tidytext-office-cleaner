# Attribution

TidyText is an expanded adaptation of **Smart Clipboard** by Rishi (2025),
originally published as an MIT-licensed GitHub Gist:

https://gist.github.com/byrishi/c53c3fcbd6f2e071d01ec6fba372a7b0

The original project provided a compact JavaScript text-cleaning routine and a
minimal demonstration page. This adaptation retains the core idea while adding
a new interface, configurable cleaning presets, safer URL handling, case tools,
live statistics, text download, responsive design, and automated tests.
